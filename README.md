# Dashboard Analítico de Vendas Globais | Power BI

Projeto prático desenvolvido no Power BI com uma base de dados fictícia e simples. O objetivo foi responder a perguntas básicas sobre vendas globais usando indicadores, gráficos e um mapa.

## Perguntas de negócio

1. Qual foi o valor total vendido?
2. Quantas vendas foram realizadas por categoria de produto?
3. Quantas vendas foram realizadas por país, considerando a prioridade de entrega?
4. Qual foi o desconto médio por subcategoria de produto?
5. Quais países tiveram o maior valor médio de venda? Essa comparação é apresentada em um mapa.

## Filtros

O dashboard permite explorar os resultados por **ano**, **segmento** e **país**.
